# Init

As an agent initialize yourself using following steps.

1. Read `Agents.md` at root.
2. Confirm: "Current Date"
3. Confirm: "Current operating system and terminal in use"

This date and terminal should be used in this session. If you issue terminal commands only issue for this terminal. eg: dont issue bash on powershell.
