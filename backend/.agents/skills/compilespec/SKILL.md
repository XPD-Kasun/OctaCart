# How to Compile spec file from discovered bc and Adrs

- bounded context is known as bc.
- architecture decision record is known as adr.
- We call `.agents/discover/{bc}.md` and `.agents/discover/context-map.md` as the *discovered domain spec* for a given bc

- Load the bounded context: read *discovered domain spec*.
  - If *discovered domain spec* doesn't exist:
    - ask the user to run the `bcdiscovery` skill first and stop.
  - If *discovered domain spec* exist:
    - Adrs are located in `.agents/specs/{bc}/ADR*.md`. It could be a single or multiple files with prefix ADR. List and read those files if any exists.
    - Once you read all adrs and *discovered domain spec*, compile the final spec for this bounded context in `.agents/specs/{bc}/domain-model.md` . Use following template for generate *domain spec*.

### Template for spec

```markdown
  ## Spec: <title>

  - **Bounded Context**: <bc>
  - **Goal**: <one or two sentences>

  ### In Scope
  - <...>

  ### Out of Scope
  - <...>

  ### Entities

  #### Entity 1

  Description about the entity
  Table of property, description, serialization type(dbtype) columns
  Optional Table of methods, description
  Optional Note: This optional section can describe supporting structs, algorithms and go code where its essential.

  ### Value Types

  #### Value Type 1
  Description about value type
  Optional table of properties if its a complex type
  Optional Method table
  Optional Note : Anything important abou this value type.

  ### Application Services

  Use all gathered infomation so far to create this.

  #### Appservice 1
  
  Purpose: Describe the purpose of this and how to be interacted with this from a handler.
  Table for method, summary
  Notes : ADR overrides and other important things.
  
  ### Domain Services

  #### Domain service 1
  
  Description of this domain service and purpose
  Participating Entities: <entity list>
  Table of methods

  ### Driven Ports

  #### Port 1

  Description
  Table of methods including method name, description
  Database mapping description if this port is a repository

  ### Adaptors

  A table of adapters with adaptor name and description

  ### Inbound 
  
  A description containing inbound commands will be handled by this bc 
  Events Consumed: If this bc consume events generated by any other discovered bc so far

  ### Outbound

  Events Published : If this bc publishes events mention them here

  ### Dependancies

  Any dependancies with other bounded contexts.

  ### Ubiquitous Language

  A table with term and meaning in this bc

  ### Polysemes

  A list of polysemes found with a description for each.

  ### Acceptance Criteria
  - [ ] <...>
```
