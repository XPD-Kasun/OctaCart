# Sequentially and Synchronously Call CreateCustomer During Registration

## The Problem
We need to establish how the customer profile creation is coordinated following successful user registration in Auth BC.

## Options Considered
- **Sequentially and synchronously invoke createCustomer immediately after creating the auth profile.**
- Publish an asynchronous event onto an event/service bus after auth registration to asynchronously create the customer profile.

## Rationale
Using an event bus overcomplicates the registration flow and adds error handling overhead with a service bus, whereas synchronous execution keeps the modular monolith flow simple and deterministic.

## Notes
Error handling should ensure atomic or consistent behavior during registration failure.
