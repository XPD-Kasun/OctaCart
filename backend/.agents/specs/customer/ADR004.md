# Restrict Inline Guest Checkout to Merchant Configuration via Special Guest Customer Profile

## The Problem
We need to determine how guest checkouts are supported and represented in the customer domain without compromising customer account models.

## Options Considered
- **Provide a merchant configuration toggle for guest checkout, and when enabled, represent inline checkouts by creating a special guest customer profile attached to checkout inline addresses.**
- Always require customer registration before placing any order.
- Allow anonymous checkouts without creating any customer entity in the Customer BC.

## Rationale
Merchants require flexibility over whether to allow guest purchases. Modeling guests as a special guest customer profile allows reusing customer address and profile associations cleanly across checkout flows.

## Notes
Inline checkout is only permitted when the merchant has configured guest checkout to true.
