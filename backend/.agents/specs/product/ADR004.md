# Title
Store Money Values in Configured Least Minor Units as Single Currency

# The Problem
How to handle multi-currency complexity and monetary precision across the product domain.

# Options Considered
- Multi-currency support with dynamic exchange rates
- Floating-point representations
- **Single tenant-configured currency stored in least minor units (integers/cents)**

# Rationale
Small-scale sellers operate in a primary business currency. Storing money in the lowest minor units (e.g., cents) avoids floating-point rounding errors and keeps pricing calculations accurate and simple.

# Notes
The currency code can be configured per tenant.
