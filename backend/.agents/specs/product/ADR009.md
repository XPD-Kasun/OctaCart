# Title
Support Product Tags for Grouping and Discovery

# The Problem
How to enable flexible, non-hierarchical categorization and search filtering for products.

# Options Considered
- Rely solely on hierarchical category tree
- Free-form text fields inside product descriptions
- **Explicit product tags associated with products**

# Rationale
Tags offer an orthogonal, lightweight classification mechanism complementary to formal category trees, making product discovery, filtering, and campaign grouping easy.

# Notes
Tag management will be refined as product filtering queries are implemented.
