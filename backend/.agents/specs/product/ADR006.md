# Title
Isolate Asset and Media Operations into Dedicated ProductMediaSvc and MediaRepo

# The Problem
Where to place media and asset management responsibilities such as image and video handling without polluting core product logic.

# Options Considered
- Handle file/image uploads directly within `ProductSvc`
- Delegate uploads to external driving controllers only
- **Separate media operations into an application service `ProductMediaSvc` with a driven port `MediaRepo`**

# Rationale
Image and video handling is a distinct infrastructural and lifecycle concern separate from catalog domain rules. Splitting it maintains single responsibility and keeps `ProductSvc` clean.

# Notes
Assets currently support images and videos.
