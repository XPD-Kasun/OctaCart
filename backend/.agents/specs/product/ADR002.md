# Product Media URL

Use Relative Paths or Direct URLs Without File Scheme for Product Media URIs

# The Problem

How to format and represent media URIs for product assets in `ProductMedia`. These media can exist in a local folder, cloud storage like S3 or mini-IO.

# Options Considered

- Use explicit URI schemes like `file:///` and full absolute paths
- Cloud-storage specific URIs (e.g., `s3://...`)
- **Relative paths for a configured directory or direct URLs without `file:///` prefix**

# Rationale

Omitting the `file:///` prefix keeps URI representations concise and clean across storage adapters, while permitting both local relative paths within a configured base directory and external web URLs.

# Notes

Assets cover images and videos. The driving port `MediaRepo` resolves locations relative to the environment's storage configuration.
