# Title
Use Command Pattern with Focused Parameter Lists for Entity Updates

# The Problem
How to update domain entities without violating encapsulation or creating bloated method signatures.

# Options Considered
- Mutation lambdas (`func(*Entity)`) modifying fields directly
- Passing all entity fields as individual method arguments
- **Command objects/structs (`xcommand` pattern) with concise parameter lists**

# Rationale
Lambda mutations are incompatible with unexported entity fields and strict encapsulation. Command structs isolate update payloads, maintain field granularity, keep method signatures compact, and allow validation within domain methods.

# Notes
If field-by-field granularity is needed, dedicated update command structs will encapsulate the specific updatable fields.
